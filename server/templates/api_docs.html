概览

鉴权方式：所有 /api/v1/* 接口需要在请求头带上 X-API-Token: wswwsw1234，或在 URL 加参数 ?token=wswwsw1234。
基础地址：http://119.145.17.34:8000  |  健康检查：/api/v1/ping（无需鉴权）

这些接口用于让 AI 或外部系统读取、创建、修改、批量管理名片页面与区块。 所有写入操作实时保存到 server/card_config.json，与后台管理界面共享同一份数据。 点击下方每个接口可展开查看请求/响应示例。

① 页面管理

GET/api/v1/pages?detail=0获取所有页面列表

detail=1 时返回每个页面的完整 sections 数组。

GET /api/v1/pages?detail=1
X-API-Token: wswwsw1234

→ { "success": true, "count": 48, "pages": [ { "id": "1-3-1", "title": "...",
    "groupId": "default", "share_title": "...", "share_desc": "...", "share_icon": "...",
    "section_count": 5, "sections": [ ... ] } ] }
GET/api/v1/pages/{page_id}获取单个页面完整配置 
GET /api/v1/pages/1-3-1
→ { "success": true, "page": { "id": "1-3-1", "title": "...", "sections": [...] } }
POST/api/v1/pages创建新页面 
POST /api/v1/pages
{ "id": "my-page", "title": "我的页面", "groupId": "default",
  "share_title": "", "share_desc": "", "share_icon": "",
  "mobile_gap": 10, "sections": [ { "type": "title", "title": "简介" } ] }

→ 201 { "success": true, "page": { "id": "my-page", ... } }
PUT/api/v1/pages/{page_id}更新页面级字段

可更新字段：title / groupId / share_title / share_desc / share_icon / mobile_gap / page_bg_theme / page_custom_bg_image / card_bg_theme / card_custom_bg_image

PUT /api/v1/pages/my-page
{ "title": "新标题", "share_title": "分享标题", "share_desc": "分享描述" }

→ { "success": true, "page": { ... } }
DELETE/api/v1/pages/{page_id}删除页面 
DELETE /api/v1/pages/my-page
→ { "success": true, "message": "页面 my-page 已删除" }

② 区块(组件)管理

GET/api/v1/pages/{page_id}/sections获取页面内所有区块 
GET /api/v1/pages/1-3-1/sections
→ { "success": true, "sections": [ { "type": "title", "uid": "sec_xxx", ... } ] }
POST/api/v1/pages/{page_id}/sections新增区块

position 可选 top / bottom(默认) / 数字索引。

POST /api/v1/pages/my-page/sections
{ "section": { "type": "image", "src": "http://.../a.png", "jump": "", "margin": 0 },
  "position": "bottom" }

→ 201 { "success": true, "section": { "uid": "sec_xxx", ... } }
GET/api/v1/sections/{uid}获取单个区块详情 
GET /api/v1/sections/sec_xxx
→ { "success": true, "section": { ... }, "pageId": "1-3-1" }
PUT/api/v1/sections/{uid}更新区块字段

按区块类型传入对应字段，例如 title 区块传 title/level/color，image 传 src/jump，grid 传 images。不可修改 uid/type。

PUT /api/v1/sections/sec_xxx
{ "title": "新标题", "color": "#667eea" }

→ { "success": true, "section": { ... } }
DELETE/api/v1/sections/{uid}删除区块（支持 tabs 内嵌） 
DELETE /api/v1/sections/sec_xxx
→ { "success": true, "message": "区块已删除" }
POST/api/v1/pages/{page_id}/sections/reorder重排区块顺序 
POST /api/v1/pages/my-page/sections/reorder
{ "uids": ["sec_aaa", "sec_bbb", "sec_ccc"] }

→ { "success": true, "sections": [ ...按新顺序... ] }

③ 批量操作

POST/api/v1/batch/update-pages批量更新多个页面的字段 
POST /api/v1/batch/update-pages
{ "pages": [
    { "pageId": "wenlv-test", "share_title": "大鹏文旅", "share_desc": "度假到哪里  大鹏文旅" },
    { "pageId": "1-3-1", "title": "新标题" }
] }

→ { "success": true, "results": [ { "pageId": "wenlv-test", "success": true, "changed": true }, ... ] }
POST/api/v1/batch/sections一个请求内批量创建/更新/删除/重排区块 
POST /api/v1/batch/sections
{ "pageId": "my-page",
  "create": [ { "type": "title", "title": "新标题" } ],
  "update": [ { "uid": "sec_xxx", "src": "http://.../new.png" } ],
  "delete": [ "sec_yyy" ],
  "reorder": [ "sec_xxx", "sec_zzz" ] }

→ { "success": true, "created": ["sec_..."], "updated": ["sec_xxx"], "deleted": ["sec_yyy"], "section_count": 3 }
POST/api/v1/batch/delete-pages批量删除页面 
POST /api/v1/batch/delete-pages
{ "pageIds": ["page-1", "page-2"] }

→ { "success": true, "deleted": ["page-1", "page-2"], "notFound": [] }

④ 分组管理

GET/api/v1/groups获取所有分组及页面数量 
GET /api/v1/groups
→ { "success": true, "groups": [ { "id": "default", "name": "默认分组", "pageCount": 12 } ] }
POST/api/v1/groups创建分组 
POST /api/v1/groups
{ "id": "new-group", "name": "新分组", "description": "说明" }

→ 201 { "success": true, "group": { ... } }
PUT/api/v1/groups/{group_id}更新分组名称/说明 
PUT /api/v1/groups/new-group
{ "name": "改后的名字" }
→ { "success": true, "group": { ... } }
DELETE/api/v1/groups/{group_id}删除分组（组内页面移回默认分组） 
DELETE /api/v1/groups/new-group
→ { "success": true, "message": "分组 new-group 已删除，组内页面已移回默认分组" }
POST/api/v1/pages/{page_id}/move移动页面到指定分组 
POST /api/v1/pages/my-page/move
{ "groupId": "new-group" }
→ { "success": true, "pageId": "my-page", "groupId": "new-group" }

⑤ 配置读取 / 搜索

GET/api/v1/config获取全量配置（basicInfo/settings/pages） 
GET /api/v1/config
→ { "success": true, "config": { "basicInfo": {...}, "settings": {...}, "pages": [...] } }
GET/api/v1/config/basic获取 basicInfo 与 settings 
GET /api/v1/config/basic
→ { "success": true, "basicInfo": {...}, "settings": {...} }
GET/api/v1/search?q=关键词&scope=all搜索页面与区块

scope 可选 all(默认) / page / section

GET /api/v1/search?q=大鹏&scope=all
→ { "success": true, "pages": [ { "id": "...", "title": "..." } ],
    "sections": [ { "uid": "...", "type": "...", "pageId": "...", "pageTitle": "..." } ] }
GET/api/v1/ping健康检查（无需鉴权） 
GET /api/v1/ping
→ { "success": true, "service": "WeChat-Card", "api": "v1" }
